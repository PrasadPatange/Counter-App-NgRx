NgRx State Management:
-> It is a package that you can install in angular app to manage application state.
-> Aims to help with the management of more complex (app-wide) state.

-> NgRx is like toy box 

The 4 pillars:
1) Action ( The "What happened") - is like button click -> I want to do something. 
2) Reducer (The "How it changes") - is like rule book -> Its Decides HOW data changes.
3) Store ( The "Current State") -> is like Home -> all data lives here.
4) Selector ( The "Piece you need") -> is like Magic Eyes -> See ONLY what you need.
5) Effects  ( Side-effects that should be trigger for certain actions (eg: send HTTP request)) -> helper Robot -> Calls API, Does Background Work.
